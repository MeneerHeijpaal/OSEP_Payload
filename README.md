# OSEP_Payload
I used the files and Attack Chain in the OSEP Labs and Exam. It creates a 64-bit and 32-bit payload that uses the Process Hollowing Technique taught in the course. I have added XOR and a Powershell script which decides (by using Is64BitProcess) which payload to send to the victim. So all you have to do is use IEX method to execute run.ps1.
